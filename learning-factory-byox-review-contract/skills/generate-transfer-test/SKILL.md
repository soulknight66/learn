# Generate a transfer test

1. Extract the canonical task's concept graph, invariants, failure modes, and prerequisite skills.
2. Change domain, API, data shape, and operational constraints while preserving the target concepts.
3. Avoid names, fixtures, and step sequences that reveal the canonical solution.
4. Write a student-safe specification, examiner rubric, hidden deterministic checks, and a reference answer.
5. Ask an independent adversarial reviewer whether shortcuts or memorized patches can pass.
6. Prove the reference passes, a plausible shallow solution fails, and hidden material is absent from the student view.
7. Label the task TRANSFER_VERIFIED only after a real unseen attempt passes meaningful validation.

Prefer one focused transfer claim over a grab bag of unrelated difficulty.
