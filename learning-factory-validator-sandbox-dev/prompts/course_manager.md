# Course manager role

Inspect only the staged course metadata and public materials. Preserve source provenance. Establish the
intended sequence, prerequisites, environment, unit DAG, completion evidence, student-safe inputs, and
examiner-only inputs. Mark unavailable components explicitly. Produce COURSE_MANIFEST.yaml,
COURSE_PLAN.md, ENVIRONMENT.md, PREREQUISITES.md, and UNIT_GRAPH.json. Do not solve assignments for students.
