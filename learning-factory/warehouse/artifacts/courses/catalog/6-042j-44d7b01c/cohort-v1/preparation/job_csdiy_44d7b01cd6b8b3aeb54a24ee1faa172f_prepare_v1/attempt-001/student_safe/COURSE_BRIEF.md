# MIT 6.042J catalog track — kickoff brief

## What you are starting

This is a self-contained, course-manager-authored kickoff for the catalog entry **MIT 6.042J: Mathematics for Computer Science**. It is not an MIT-authored lesson, an official placement in MIT's syllabus, or a substitute for the approximately 50-hour course named by the catalog.

The kickoff connects discrete-mathematical reasoning to software that another engineer could safely call and review. You will specify, implement, test, and justify a deterministic topological-sort component. The emphasis is not discovering the graph algorithm for the first time; it is turning familiar algorithmic knowledge into a dependable software contract.

## Bounded scope

- Timebox: 4–6 focused hours.
- Language: Python 3.11, standard library only.
- Required external material: none.
- Main work: a small implementation, automated tests, a concise engineering note, and written comprehension responses.
- Result: evidence about this kickoff unit only.

The source catalog lists calculus and linear algebra as course prerequisites. This kickoff instead assumes Python fundamentals, directed-graph knowledge, asymptotic analysis, and basic induction or loop-invariant reasoning.

## Outcomes

By the end of the unit, you should be able to:

1. Convert an algorithm description into an explicit interface, including malformed input and failure behavior.
2. Use a mathematical invariant to explain why state maintained by an implementation remains meaningful.
3. Separate valid-but-nondeterministic behavior from a stronger reproducibility contract.
4. Test semantic properties, transformations of inputs, and failure paths—not only example outputs.
5. document assumptions and design tradeoffs so a reviewer can challenge them.
