# Stanford CS142: Web Applications — Kickoff Brief

## What this packet is

The catalog describes CS142 as a Stanford web-applications course covering HTML, CSS, JavaScript, React, Node, Express, and web security. This packet prepares one bounded, manager-authored kickoff unit for a learner who already has strong algorithmic problem-solving skills and wants more experience building maintainable software.

This is not a copy or reconstruction of a Stanford lesson or project. Completing it does not complete CS142, replace its prerequisites, or establish credit in any course.

## First-unit focus

You will build an **Algorithm Run Log**, a small browser application that records measurements from algorithm experiments. The domain is deliberately familiar so that the new work is software engineering:

- turning prose requirements into observable behavior;
- separating domain rules from the browser and persistence;
- validating hostile or malformed input at boundaries;
- testing deterministic logic and failure paths; and
- documenting how another developer can run and verify the result.

Plan for about eight focused hours. Keep the implementation deliberately small; frameworks, servers, accounts, networking, and elaborate visual design are outside this unit.

## Learning outcomes

By the end of the unit, you should be able to:

1. implement a small application from an explicit behavioral contract;
2. maintain a clean boundary between pure logic and side effects;
3. preserve state invariants across create, remove, load, and failure operations;
4. demonstrate important behavior with deterministic automated tests; and
5. explain the design in terms another engineer can review.

## Starting assumptions

You should be comfortable with functions, arrays, records, sorting, boundary cases, a terminal, and basic source control. Prior browser programming is helpful but not required. The catalog lists CS107 and CS108 as prerequisites; this packet does not supply or validate that background.
