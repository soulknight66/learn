# Learner debugging log

This is a concise chronological record of hypotheses and observable evidence. The fuller artifact
log is `submission/DEBUG_LOG.md`. No failure below is invented, and probes print observation metadata
only.

## 1. Initial full-run compatibility check

**Hypothesis:** The initial frozen-dataclass implementation will load and execute under the
repository's prescribed `python3` command.

**Command (from `submission/`):**

```text
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

**Observation:** Exit 1. Test discovery produced one failed module and no executed contract tests.
The traceback ended with `ModuleNotFoundError: No module named 'dataclasses'` and showed a Python 3.6
standard-library path.

**Revision:** Replaced the frozen dataclass with `typing.NamedTuple`, removed the Python 3.10
`bytes | bytearray` annotation, and updated the immutability test to the exception actually raised by
an immutable named tuple. The public fields and behavior remained unchanged.

## 2. Full regression on the available interpreter

**Hypothesis:** The Python 3.6-compatible representation preserves all request behavior.

**Commands:**

```text
python3 --version
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

**Observation:** Python reported version 3.6.8. Exit 0; 13 tests passed. A later final run of the
exact test command also exited 0 with 13 tests and `OK` (observed runtime 0.006 seconds).

**Decision:** Retained `NamedTuple`; it is immutable, inspectable, standard-library-only, and
compatible with the actual prerequisite runtime.

## 3. Hardened pre-mutation invariant

**Hypothesis:** A 17-byte hardened rejection neither calls the common copy helper nor changes any
byte in a fresh frame.

**Command (from `submission/tests/`):**

```text
PYTHONPATH=../src python3 -m unittest -v test_model.RequestBoundaryTests.test_hardened_rejection_precedes_copy_and_leaves_frame_untouched test_model.IsolationAndPrivacyTests.test_requests_are_isolated_after_authorization_change_and_rejection test_model.IsolationAndPrivacyTests.test_results_and_diagnostics_do_not_expose_raw_payload
```

**Observation:** Exit 0; all 3 focused tests passed. The copy spy recorded no call, the injected
24-byte frame equaled its initial snapshot, subsequent requests were clean, captured stdout/stderr
were empty, and the distinctive payload was absent from result representations.

**Decision:** Kept length validation before `_copy_bytes`. Both instrumentation and state comparison
are necessary because checking only the final role value could miss copy-then-repair behavior.

## 4. Boundary and state probe

**Hypothesis:** Role corruption precedes canary corruption by one input byte, and neither persists to
the next request.

**Command (from `submission/`):**

```text
PYTHONPATH=src python3 -c 'from frameguard.model import vulnerable_request, hardened_request; crossing = bytes(16) + bytes([1]); canary_hit = bytes(18); print("vulnerable_crossing", vulnerable_request(crossing)); print("hardened_crossing", hardened_request(crossing)); print("vulnerable_canary_hit", vulnerable_request(canary_hit)); print("fresh_afterward", vulnerable_request(bytes()))'
```

**Observation:** Exit 0. The vulnerable crossing result was accepted/granted with length 17,
overflow 1, and intact canary. Hardened rejected the same length with `PAYLOAD_TOO_LONG`. The
18-byte vulnerable result had overflow 2 and `canary_intact=False`. The subsequent empty request was
accepted, denied access, and had an intact canary.

**Decision:** Documented authorization integrity, canary integrity, and request isolation as
separate properties. The probe persisted no payload or full-frame dump.

## 5. Manifest capture

**Hypothesis:** Every source, test, and Markdown artifact other than the report can be identified by
a reproducible digest.

**Command:**

```text
sha256sum src/frameguard/__init__.py src/frameguard/model.py tests/test_model.py THREAT_MODEL.md DESIGN.md DEBUG_LOG.md
```

**Observation:** Exit 0 and six SHA-256 lines were produced; they were copied into
`submission/REPORT.md` before that report was created.

**Decision:** Excluded `REPORT.md` as required and did not treat generated bytecode caches as source,
test, or Markdown submission artifacts.
