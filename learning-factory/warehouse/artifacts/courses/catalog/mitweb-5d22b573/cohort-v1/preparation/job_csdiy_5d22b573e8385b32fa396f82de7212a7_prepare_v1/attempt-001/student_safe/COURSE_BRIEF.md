# MIT Web Development Crash Course: kickoff brief

## What this packet is

This is one bounded kickoff unit, **A Reliable Browser Vertical Slice**. It is designed for a strong algorithms student who can already program and now wants practice turning code into a small, testable product. Completing it is evidence for this unit only; it is not completion of the MIT course or of a full-stack curriculum.

Plan for about six focused hours. You can stop at the stated boundary even if you see interesting extensions.

## The engineering goal

You will build a small browser-based work queue using HTML, CSS, and JavaScript. The visible feature is deliberately modest. The real work is to make requirements precise, keep deterministic logic separate from browser effects, cover boundary behavior with tests, support basic accessibility, and leave reproducible evidence for another engineer.

By the end of the unit, you should be able to:

- turn a short product description into observable behaviors;
- isolate validation, ordering, and state transitions from DOM and storage code;
- connect semantic HTML, usable CSS, and browser JavaScript into one vertical slice;
- test edge cases and explain the limits of the implementation.

## Starting assumptions

You should already be comfortable with functions, collections, conditionals, and running a program from a terminal. Familiarity with JavaScript syntax is helpful but not required; language reference documentation may be used and cited in your engineering note.

## Unit boundary

The required product is a single-user, in-browser application. There is no server, authentication, collaboration, framework, deployment, or course-wide capstone in this unit. Do not expand the scope to compensate for unavailable upstream material.

Read `STUDY_TASK.md`, build the requested artifact in your assigned learner workspace, then answer `COMPREHENSION.md` in your own words. Preserve the commands and outputs you use as verification evidence.
