# Debugging exercises

These exercises are diagnosis-only. Reproduce each failure with the smallest byte/output sequence,
state the violated requirement, and propose a test before proposing a fix.

- `scancode_state/`: a prefix-state bug that appears only across calls.
- `terminal_scroll/`: a last-row memory-safety bug.

Answers are not stored in this learner-facing directory. Each exercise has a separately sealed answer.
