# Debugging exercises

Each exercise presents an isolated defective implementation fragment and a
symptom. Diagnose it before revealing that exercise’s own sealed answer.

- `exercise-01`: valid branches sometimes fail verification or jump into an
  instruction operand.
- `exercise-02`: diagnostics after Windows-style line endings report the wrong
  line.

Answers are deliberately colocated only at
`debugging/exercise-N/sealed/ANSWER.md`; none is in starter or public tests.
