# Benchmark plan

Benchmark material is evaluator-owned and excluded from the learner view. The
sealed driver measures compile-and-run wall time for generated arithmetic and
loop programs using an explicitly selected executable.

No benchmark was executed during generation and no timing or throughput claim is
recorded. Running a benchmark does not itself justify a `BENCHMARKED` label; the
validator must retain toolchain, machine, workload, warmup, repetition count, raw
observations, and command provenance.
