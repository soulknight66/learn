# Code-review exercises

Review `bytecode-validation/candidate.js` as though its input crosses a trust boundary. Identify
specific programs that pass the candidate predicate but cannot be safely executed. Classify each
finding as a shape, argument, control-flow, stack, scope, resource, or sequencing defect, and propose
tests before proposing code changes.

The evaluator review is stored only under `sealed/review_exercises/bytecode-validation/`.
