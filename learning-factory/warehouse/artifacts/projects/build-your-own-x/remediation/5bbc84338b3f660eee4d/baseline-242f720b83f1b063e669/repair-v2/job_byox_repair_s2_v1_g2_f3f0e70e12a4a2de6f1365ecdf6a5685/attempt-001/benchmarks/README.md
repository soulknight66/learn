# Benchmark protocol

Distribution boundary: this root is instructor-only, and this pack defines no learner reveal stage for
it.

Benchmarking is optional and no performance label is claimed. If measuring, separate reader construction
from evaluation, warm up outside the timed region, use a fixed program and iteration count, record the
exact interpreter path/version, and report every sample rather than only the best. Compare semantics
before speed. A reference-only deterministic smoke harness is kept with sealed material.
