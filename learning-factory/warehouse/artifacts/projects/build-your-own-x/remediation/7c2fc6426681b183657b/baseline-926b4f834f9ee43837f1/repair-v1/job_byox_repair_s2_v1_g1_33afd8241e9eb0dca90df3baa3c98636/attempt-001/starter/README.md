# Starter

`forth.S` is a freestanding, buildable stub. It demonstrates the required assembler dialect,
entry-point symbol, system-call style, and non-executable-stack annotation, but intentionally exits
with the contract's error status.

Implement the milestones from the root `README.md` here. You may split your assembly into more files
if you also extend the build helper or Makefile deterministically. Do not inspect or copy evaluator
material from `sealed/`.
