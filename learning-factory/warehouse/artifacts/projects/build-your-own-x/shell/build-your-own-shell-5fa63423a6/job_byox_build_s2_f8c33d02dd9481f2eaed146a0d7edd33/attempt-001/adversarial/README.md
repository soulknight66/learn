# Adversarial validation index

Adversarial cases are held with the sealed reference tests so learner-visible tests do not become an answer oracle. The generated suite covers unterminated quoting, trailing escapes, empty words, operator adjacency, comments at different boundaries, duplicate redirections, malformed pipelines, absent executables, explicit-redirection precedence, a low descriptor limit, and real PTY interrupt delivery.

This directory contains no hidden grader or validation label. Independent harness validators remain authoritative.
