# Starter

Implement the TODOs in `src/`. Preserve the CommonJS API in `index.js` and do not add third-party
dependencies.

A useful order is:

1. `compose.js`
2. `router.js`
3. `response.js`
4. `application.js`
5. `body-json.js`

Run from the repository root:

```sh
node --test public_tests/*.test.js
```

The initial scaffold is expected to fail behavioral tests. Public checks are not exhaustive; use
`REQUIREMENTS.md` as the contract.
